# Quick Start: AI Roadmaps 🚀

## 🎯 Two Learning Paths

### 🎯 Learning from Scratch
**When to use**: You're new to this technology  
**What you get**: 5-8 comprehensive steps, 4-8 weeks  
**Example**: "I want to learn React from scratch"

### 🚀 Upgrade Skills  
**When to use**: You know it, but want latest features  
**What you get**: 3-5 focused steps, 1-2 weeks  
**Example**: "I know React, teach me React 19 features"

---

## 📝 How to Create a Roadmap

1. Click **"Create AI Roadmap"** button
2. Enter technology name (e.g., "TypeScript")
3. Choose path type:
   - **🎯 Scratch** = Beginner
   - **🚀 Upgrade** = Advanced
4. Select category
5. Click **"Generate Roadmap"**
6. Wait 3-5 seconds
7. Done! ✅

---

## ✅ Track Your Progress

- ○ Click the **circle** to mark step complete → ✓
- Progress bar updates automatically
- Everything saves to your browser

---

## ⬇️ Download Roadmap

**From card**: Click download icon (⬇️)  
**From detail view**: Click "Download" button  
**Format**: Markdown (.md file)  
**Use**: Study offline, share with team

## 🎨 Quick Tips

✅ **Use specific names**: "React 19" not just "React"  
✅ **Check prerequisites**: Listed at top of roadmap  
✅ **Follow in order**: Steps build on each other  
✅ **Use resources**: Click links to official docs  
✅ **Track time**: Each step shows estimated hours  
✅ **Download early**: Save before browser clear  

---

## 🚀 Pro Tips

1. **Combine paths**: Create both Beginner + Upgrade for same tech
2. **Check outcomes**: See what you'll build
3. **Set deadlines**: Use estimated time to plan
4. **Share roadmaps**: Download and send to teammates
5. **Regular updates**: Delete completed, create new ones
